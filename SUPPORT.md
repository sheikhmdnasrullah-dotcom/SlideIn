# Support

This project is in **beta** and maintained by a solo developer in public.

## How to get help

1. **Read the docs first**: `docs/development/LOCAL_SETUP.md` (quickstart
   + troubleshooting), `docs/development/TESTING.md` (test matrix),
   `docs/project/PROJECT_AUDIT.md` (what works, what doesn't).
2. **Search existing issues** before opening a new one.
3. **Open a GitHub issue** for bugs or concrete feature requests, using the
   issue templates. Include: what you ran, what you expected, what happened,
   your OS/runtime versions.

## What to expect

- Honest answers about what is and isn't implemented
  (`docs/project/CURRENT_STATE.md` is the source of truth).
- No guaranteed response time. This is a beta project without a support
  SLA.
- Security issues: follow `SECURITY.md` — do **not** open a public issue.

## What is not offered yet

- Managed hosting / paid support (not available today)
- Enterprise features, compliance certifications, or uptime guarantees
